## About

Gaming taught me systems thinking before I knew that's what it was called — spawn rates, cooldowns, state machines, resource management. Turns out that's just programming with better graphics.

Now I'm doing the same thing without the graphics: working through **CS50**, writing Python, and building a Discord bot for my server because I wanted to see what's actually happening on the other side of the games I play.

- Learning in public, breaking things on purpose to understand why they broke
- More interested in *why* something works than getting it working and moving on
- Still gaming — research, obviously
